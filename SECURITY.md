# Security policy

Please report suspected vulnerabilities privately through GitHub's **Security**
tab instead of opening a public issue. Include the script version, Windows and
OneNote versions, reproduction steps, and whether notebook content was changed.

This project does not upload data. Recovery journals are stored locally under
`%LOCALAPPDATA%\OneNotePageGuides\Backups` and may contain notebook/page names,
identifiers, XML, and embedded guide images. Treat those files as private.
